## Image Specifications

- **Format:** PNG or JPG
- **Aspect Ratio:** 16:9 (1200x675, 1600x900, or 1920x1080)
- **File Size:** Under 500KB each (optimize for web)
- **Quality:** High resolution, crisp UI elements
- **Style:** Clean screenshots with minimal clutter

## Tips for Great Screenshots

1. **Use clean, representative screens** - Show your best UI work
2. **Include real data** - But anonymize sensitive information
3. **Show key features** - Highlight what makes each project unique
4. **Good lighting/contrast** - Ensure text is readable
5. **Consistent style** - Similar screenshot style across all projects
